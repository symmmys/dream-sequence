SOMNIUM — D&D GRID REFINEMENT
============================

This update refines tactical character positioning, movement/action economy, Dash,
and flight altitude while preserving the previously repaired editor and grid controls.

RECOMMENDED INSTALLATION
------------------------
1. Make a backup of your current Somnium project folder.
2. Extract the complete project archive.
3. Replace your working project folder with the extracted project contents.
4. Start Somnium through your usual local development server.

The complete archive is the safest option because it includes all synchronized source,
style-conformance documentation, project-state notes, and regenerated source summaries.
