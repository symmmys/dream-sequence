ROOT CAUSE CONFIRMED
Phase 9's world-topology.js directly called createSpatialCorridor(). Phase 10
changed this module to call createSpatialAnomaly(), but the updated demo topology
import did not cache-bust world-topology.js. The browser could therefore combine
the new Phase 10 demo topology with the cached Phase 9 WorldTopology module.

The Phase 9 module passed a slice-transition anomaly to the Bezier-only corridor
constructor, producing the reported missing-centreline-control-points exception.

- Bumped the application build/cache identifier.
- Versioned the WorldTopology dependency and the changed anomaly-module import
  edges so the browser loads a coherent Phase 10 module graph.
- No movement, geometry, slice, anomaly-region, or chunk-address behavior was
  changed by this startup hotfix.
